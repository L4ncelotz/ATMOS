# assets/

This directory holds media for the project's README.

- `demo.svg` — static fallback while a real terminal recording is
  being prepared. The README links to `demo.gif` so a future
  `asciinema` or `ttyrec`-to-`gif` capture should land at
  `assets/demo.gif` and this `demo.svg` can be deleted.

ATMOS is a terminal-native application: there is no GUI to
screenshot. The SVG above is the closest static approximation.
