# ATMOS assets

This directory holds media for the project's README and documentation.

ATMOS is a terminal-native application: there is no GUI to screenshot.
The ASCII-art blocks in `README.md` and `CHANGELOG.md` double as both
preview and visual smoke test of the rendering rules.

If you record a real terminal capture (e.g. with
[asciinema](https://asciinema.org/) or
[ttyrec](https://github.com/expectocode/ttyrec)), drop the
`cast`/`gif` file here and link it from `README.md`.
